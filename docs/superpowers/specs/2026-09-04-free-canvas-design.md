# Mindmap PPT 自由画布设计

## 目标

把当前由播放器强制控制视角的导图，改造成“自由且有节奏”的演示画布。

- 自由：用户始终可以拖动、缩放和查看全局，普通重绘不会抢走用户视角。
- 有节奏：一次翻页只展开一个完整逻辑单元，新内容以明确但克制的动画出现。

播放器负责内容何时出现，不决定用户必须看哪里。

## 用户体验

### 自由浏览

- 在画布空白区域按住并拖动，可以自由平移画布。
- 鼠标滚轮和触控板双指滚动用于平移；支持横向和纵向移动。
- 触控板捏合或 `Ctrl/Cmd + 滚轮` 围绕指针位置缩放。
- 缩放不再使用固定的 70% 下限。下限根据当前已显示内容和视口动态计算，确保可以看到全局。
- 缩放上限保留合理约束，避免无限放大后迷失。
- 平移有软边界：允许内容靠近或部分离开视口，但始终保留一部分导图可见，避免把整张图拖丢。
- 提供明确的“适应窗口”操作，一次将当前已显示内容完整放入视口。

### 节奏播放

- 方向键、Page Up / Page Down、空格和界面按钮负责切换逻辑单元。
- 鼠标滚轮和触控板不再承担翻页，避免与自由画布操作冲突。
- 一次前进展开一个 `@unit` 逻辑单元，单元内部节点同时出现。
- 新逻辑单元已经位于视口内时，不移动镜头。
- 新逻辑单元完全位于视口外时，只做刚好使它可见的最小平移，不强制居中。
- 用户手动改变过视角后，后续布局重算只处理越界，不恢复播放器预设镜头。

### 视觉反馈

- 新单元沿用现有节点和连线出现动画，但同一单元作为一个整体节拍出现。
- 当前单元保持清晰的选中状态，不增加持续闪烁或扩散光环。
- 拖动画布时显示抓取光标；松手后停止，不加入惯性漂移作为第一版能力。
- 控制面板增加“适应窗口”，并保留当前缩放比例显示。
- 第一版不增加“小地图”和“演示/浏览模式”开关，避免额外操作负担。

## 视角与边界模型

导图布局和镜头状态分离：

- 布局模型输出节点位置、连线和当前内容边界。
- 镜头状态独立保存平移位置与缩放比例。
- 用户手势只修改镜头状态，不改变节点布局或播放进度。
- 播放进度只修改可见节点集合，再根据新内容边界校正镜头。
- 适应窗口根据“当前可见内容边界 + 安全边距”计算缩放和位置。

边界规则：

- “适应窗口比例”是在内容四周保留至少 48px 安全边距后，能够完整显示当前内容的最大比例。
- 最小缩放值取“适应窗口比例的 90%”，并限制在 5%–70% 之间，使用户可以比适应窗口略微缩得更远。
- 最大缩放值设为 200%。
- 平移限制以内容边界和视口尺寸计算，而不是使用固定画布坐标。
- 当内容尺寸小于视口时，允许在安全范围内移动，但默认保持内容居中。

## 输入映射

| 输入 | 行为 |
| --- | --- |
| 拖动画布空白区域 | 平移 |
| 鼠标滚轮 / 触控板双指滚动 | 平移 |
| 触控板捏合 | 围绕指针缩放 |
| `Ctrl/Cmd + 滚轮` | 围绕指针缩放 |
| 移动端单指拖动空白区域 | 平移 |
| 移动端双指捏合 | 围绕双指中心缩放 |
| 方向键、Page Up / Page Down | 上一个 / 下一个逻辑单元 |
| 空格 / Shift + 空格 | 下一个 / 上一个逻辑单元 |
| “适应窗口”按钮 | 完整显示当前已展开内容 |
| 点击节点 | 保留现有节点查看能力，不改变播放进度 |
| 点击图片 | 打开图片预览，不触发画布拖动 |

画布拖动只从空白区域开始。控制面板、节点、图片和滑条上的操作不得误触发平移。

## 状态与数据流

播放器维护三类相互独立的状态：

1. 内容状态：当前逻辑单元和已显示节点。
2. 布局状态：节点位置、连接线和内容边界。
3. 镜头状态：平移、缩放以及用户是否主动调整过视角。

数据流：

1. 翻页更新内容状态。
2. 内容状态生成新的布局状态。
3. 镜头先保留原状态，再做边界校正。
4. 仅当新单元完全不可见时，执行最小可见平移。
5. 用户手势直接更新镜头并重新渲染，不重新计算播放进度。

## 兼容性

- `@unit`、`@image` 和旧的无 `@unit` 内容格式保持不变。
- 没有 `@unit` 的内容仍按节点逐步播放，但画布交互同样自由。
- 保持项目无运行时依赖。
- 桌面鼠标、触控板、键盘和移动端触控都需要可用。
- 尊重键盘焦点和图片预览，不让全局快捷键破坏输入控件操作。

## 验收标准

### 自动化验证

- 适应窗口计算能在不同视口和内容边界下完整容纳导图。
- 指针缩放后，指针下的逻辑位置保持稳定。
- 平移无法把全部内容拖出视口。
- 翻页时，新单元可见则镜头不动；完全不可见则只做最小平移。
- 用户手动视角不会被普通重绘重置。
- 原有逻辑单元、图片和旧内容兼容测试继续通过。

### 真实浏览器验证

- 在 1440×900 视口中，结束总览可以一键完整显示。
- 大型导图可以缩小到全局，也可以放大后拖动查看局部。
- 连续拖动、缩放和翻页不会出现跳回、抖动或视角丢失。
- 节点、图片和控制面板操作不会误触发画布拖动。
- 鼠标、触控板、键盘与移动端触控分别完成一轮验收。

## 暂不包含

- 小地图。
- 无限画布。
- 惯性滚动或惯性拖动。
- 演示模式与浏览模式切换。
- 多人协作、编辑节点或运行时修改导图内容。
